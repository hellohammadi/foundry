# No product-market fit
topic: strategy

## Symptoms
- Sales require heavy convincing every time
- Customers like it but don't love it
- Feature requests point in many directions

## Root causes
- Serving too broad an audience
- Solving a nice-to-have, not a must-have problem
- Competing on features instead of a clear unique value

## How to confirm
- Ask customers: how would you feel if you could no longer use this? Aim for 40% "very disappointed"
- Find which customer type gets the most value and refers others

## Fixes
- Narrow to the segment that loves you most
- Rebuild messaging and product around their main use case
- Remove features that serve no core segment
- Raise prices for the segment that values you most

## 30-day starter plan
- Week 1: Survey customers with the "very disappointed" question
- Week 2: Interview the happiest customers and find the shared pattern
- Week 3: Rewrite positioning for that segment
- Week 4: Run a focused campaign aimed only at that segment

## Metrics
- Share of "very disappointed" responses
- Organic referrals
- Sales cycle length
